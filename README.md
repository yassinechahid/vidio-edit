# Next.js Template

A clean Next.js template with TypeScript, Tailwind CSS, and internationalization support.

## Features

- ⚡ Next.js 15 with App Router
- 🎨 Tailwind CSS for styling
- 🌍 i18next for internationalization (English, French, Arabic)
- 🌓 Dark mode support
- 📱 Responsive design
- 🎭 Material Tailwind components
- 📝 TypeScript for type safety
- 🎯 ESLint configuration

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `src/app/` - Next.js app directory
- `src/components/` - Reusable React components
- `src/contexts/` - React context providers
- `src/hooks/` - Custom React hooks
- `src/types/` - TypeScript type definitions
- `src/utils/` - Utility functions
- `public/locales/` - Translation files for i18next

## Available Scripts

- `npm run dev` - Start development server with Turbopack
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint

## Customization

This is a template project. Start building your application by:

1. Adding your content to `src/app/page.tsx`
2. Creating new components in `src/components/`
3. Adding translations to `public/locales/`
4. Placing your assets in `public/assets/`
